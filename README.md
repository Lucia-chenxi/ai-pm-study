# AI 产品经理学习手册

网站入口：`index.html`。公开资料位于 `data/resources.json`。

在资料书架填写链接后，网站会前往 GitHub 创建一条资料请求。仓库所有者确认提交 Issue 后，GitHub Actions 更新公开资料文件；网页部署完成后，其他设备即可读取。未提交的请求只暂存在当前浏览器，并显示“待发布”。

个人笔记和上传文件保存在浏览器中，不写入公开仓库。请勿在公开资料的标题、标签或 URL 中放入密码、令牌或私人信息。

本地检查：`node public-data.test.js`、`node --check app.js`。
